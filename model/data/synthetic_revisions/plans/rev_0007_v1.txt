SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 3
DURATION: 70 minutes
CLASS SIZE: 32

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- solve the main idea of passage
- compare main idea

PCK:
Content is accurate and appropriate to grade level with worked examples for passage.

RESOURCES:
a projector where power is available; specimens of main idea.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Teacher revises the previous lesson on context clues. This is connected to today's topic, Comprehension Skills, and in particular to passage.

CORE POINTS:
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.
Comprehension Skills involves summary. Learners should note that summary is a key point of today's lesson.
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(15 minutes) Teacher writes notes about passage on the board for learners to copy.
(20 minutes) Learners practise solving exercises on main idea in pairs.
(20 minutes) Learners role-play the process of summary in front of the class.
(10 minutes) Teacher demonstrates inference using TLMs while learners observe and ask questions.
(20 minutes) In groups, learners investigate context clues and record their observations.

EVALUATION:
1. Describe how passage occurs.
2. What is meant by main idea?
3. Explain the role of summary in your own words.

DIFFERENTIATION:
Learners are grouped by ability for the practice task. Learners may first discuss in their mother tongue.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain passage clearly.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
Closing questions check whether the objective was met.
