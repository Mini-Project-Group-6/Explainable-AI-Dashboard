SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 2
DURATION: 36 minutes
CLASS SIZE: 49

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- evaluate the main idea of context clues
- explain inference

PCK:
Content is broadly correct but thin and generic for context clues.

RESOURCES:
TLMs will be provided.

INTRODUCTION:
Teacher reviews learners' previous knowledge of summary.

CORE POINTS:
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
Teacher demonstrates context clues using TLMs while learners observe and ask questions.
Through question and answer, learners brainstorm what they know about inference.
Teacher writes notes about passage on the board for learners to copy.
In groups, learners investigate main idea and record their observations.
Teacher explains summary to the class.

EVALUATION:
1. List 4 examples of context clues.
2. What is meant by inference?
3. Explain the role of passage in your own words.

DIFFERENTIATION:
All learners will do the same task.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain context clues clearly.

SEQUENCING:
A phase is missing and timings are absent.

CLOSURE:
Learners summarise in their own words what they have learnt.
