SUBJECT: Mathematics
TOPIC: Percentages
CLASS: JHS 1
DURATION: 60 minutes
CLASS SIZE: 55

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- state the main idea of fraction
- compare profit

PCK:
Content is accurate and appropriate to grade level with worked examples for fraction.

RESOURCES:
a projector where power is available; a whiteboard marker for key terms; counters for the group task.

INTRODUCTION:
The objective is shared with learners at the start.

CORE POINTS:
Percentages involves fraction. Learners should note that fraction is a key point of today's lesson.
Percentages involves profit. Learners should note that profit is a key point of today's lesson.
Percentages involves percent. Learners should note that percent is a key point of today's lesson.
Percentages involves discount. Learners should note that discount is a key point of today's lesson.
Percentages involves conversion. Learners should note that conversion is a key point of today's lesson.
Percentages involves decimal. Learners should note that decimal is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(20 minutes) Learners discuss fraction in small groups and present their findings to the class.
(10 minutes) Teacher reads the section on profit from the textbook.
(15 minutes) Teacher demonstrates percent using TLMs while learners observe and ask questions.
(15 minutes) Learners practise solving exercises on discount in pairs.

EVALUATION:
1. Calculate the answer to the exercise on fraction on the board.
2. Explain the role of profit in your own words.
3. What is meant by percent?

DIFFERENTIATION:
Participation is shared fairly between girls and boys. Groups are mixed ability so learners support one another. An extension task is ready for learners who finish early.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain fraction clearly.

SEQUENCING:
Starter, main, and plenary all present with coherent progression; each activity builds on the previous; timings are realistic and balanced. Phase timings are shown throughout.

CLOSURE:
The main points are consolidated on the board. Learners summarise in their own words what they have learnt. Closing questions check whether the objective was met.
