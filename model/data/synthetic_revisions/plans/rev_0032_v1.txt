SUBJECT: Mathematics
TOPIC: Percentages
CLASS: JHS 2
DURATION: 60 minutes
CLASS SIZE: 54

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- state the main idea of conversion
- compare decimal

PCK:
Content is accurate throughout, anticipates common misconceptions for conversion, and includes pitched worked examples.

RESOURCES:
cardboard cut-outs prepared beforehand; worksheets on decimal.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Learners recall what they already know about profit. This is connected to today's topic, Percentages, and in particular to conversion.

CORE POINTS:
Percentages involves conversion. Learners should note that conversion is a key point of today's lesson.
Percentages involves decimal. Learners should note that decimal is a key point of today's lesson.
Percentages involves percent. Learners should note that percent is a key point of today's lesson.
Percentages involves fraction. Learners should note that fraction is a key point of today's lesson.
Percentages involves discount. Learners should note that discount is a key point of today's lesson.
Percentages involves profit. Learners should note that profit is a key point of today's lesson.
Percentages involves conversion. Learners should note that conversion is a key point of today's lesson.
Percentages involves decimal. Learners should note that decimal is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(20 minutes) Learners role-play the process of conversion in front of the class.
(20 minutes) In groups, learners investigate decimal and record their observations.
(15 minutes) Learners practise solving exercises on percent in pairs.
(15 minutes) Teacher demonstrates fraction using TLMs while learners observe and ask questions.
(20 minutes) Teacher explains discount to the class.

EVALUATION:
1. What is meant by conversion?

DIFFERENTIATION:
An extension task is ready for learners who finish early. Slower learners receive targeted support during the group work.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain conversion clearly.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
The main points are consolidated on the board. Learners state the key points to the class. Teacher asks two questions to confirm attainment before dismissal.
