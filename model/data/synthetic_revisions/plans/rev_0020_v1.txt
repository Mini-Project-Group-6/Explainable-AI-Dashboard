SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 3
DURATION: 42 minutes
CLASS SIZE: 55

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- explain a curriculum indicator for Comprehension Skills using at least two evidence
- list the key idea of summary in one lesson
- evaluate main idea with a clear example

PCK:
Content is broadly correct but thin and generic for summary.

RESOURCES:
real objects collected from the school compound; worksheets on main idea; chalkboard and chalk.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Learners recall what they already know about inference. This is connected to today's topic, Comprehension Skills, and in particular to summary.

CORE POINTS:
Comprehension Skills involves summary. Learners should note that summary is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
Through question and answer, learners brainstorm what they know about summary.
Teacher writes notes about main idea on the board for learners to copy.
Teacher demonstrates context clues using TLMs while learners observe and ask questions.
Learners role-play the process of passage in front of the class.
In groups, learners investigate inference and record their observations.
Teacher demonstrates summary using TLMs while learners observe and ask questions.

EVALUATION:
1. Calculate the answer to the exercise on summary on the board.
2. What is meant by main idea?

DIFFERENTIATION:
Provision is made for a learner with a hearing impairment.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain summary clearly.

SEQUENCING:
A phase is missing and timings are absent.

CLOSURE:
Teacher summarises the key points of the lesson. Learners state the key points to the class. Teacher asks two questions to confirm attainment before dismissal.
