SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 2
DURATION: 60 minutes
CLASS SIZE: 34

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- evaluate the main idea of context clues
- explain inference

PCK:
Content is broadly correct but thin and generic for context clues.

RESOURCES:
TLMs will be provided.

INTRODUCTION:
Teacher reviews learners' previous knowledge of summary.

CORE POINTS:
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(15 minutes) Teacher demonstrates context clues using TLMs while learners observe and ask questions.
(15 minutes) Through question and answer, learners brainstorm what they know about inference.
(20 minutes) Teacher writes notes about passage on the board for learners to copy.
(10 minutes) In groups, learners investigate main idea and record their observations.
(15 minutes) Teacher explains summary to the class.

EVALUATION:
1. List 4 examples of context clues.
2. What is meant by inference?
3. Explain the role of passage in your own words.

DIFFERENTIATION:
Groups are mixed ability so learners support one another. Provision is made for a learner with a hearing impairment.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain context clues clearly.

SEQUENCING:
Starter, main, and plenary all present with coherent progression; each activity builds on the previous; timings are realistic and balanced. Phase timings are shown throughout.

CLOSURE:
Teacher summarises the key points of the lesson. Learners state the key points to the class. Teacher asks two questions to confirm attainment before dismissal.
