SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 3
DURATION: 60 minutes
CLASS SIZE: 43

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- list a curriculum indicator for Comprehension Skills using with the aid of real objects evidence
- calculate the key idea of main idea in one lesson
- construct passage with a clear example

PCK:
Content is accurate throughout, anticipates common misconceptions for main idea, and includes pitched worked examples.

RESOURCES:
a projector where power is available; a labelled diagram of passage; real objects collected from the school compound.

INTRODUCTION:
Teacher opens with a short hook to settle the class. This is connected to today's topic, Comprehension Skills, and in particular to main idea.

TEACHER-LEARNER ACTIVITIES:
(20 minutes) Learners practise solving exercises on main idea in pairs.
(10 minutes) Teacher writes notes about passage on the board for learners to copy.
(20 minutes) In groups, learners investigate summary and record their observations.
(20 minutes) Teacher demonstrates inference using TLMs while learners observe and ask questions.
(20 minutes) Learners discuss context clues in small groups and present their findings to the class.

EVALUATION:
1. Describe how main idea occurs.
2. Describe how passage occurs.
3. Describe how summary occurs.

DIFFERENTIATION:
Key terms are explained in the local language where needed. A challenge question is provided for the most able. Groups are mixed ability so learners support one another.

EXPLANATION STRATEGY:
Teacher uses an analogy, diagram, and demonstration from the Ghanaian classroom context to explain main idea.

SEQUENCING:
Starter, main, and plenary all present with coherent progression; each activity builds on the previous; timings are realistic and balanced. Phase timings are shown throughout.

CLOSURE:
The main points are consolidated on the board.
