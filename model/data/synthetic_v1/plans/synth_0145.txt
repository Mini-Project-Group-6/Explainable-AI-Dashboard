SUBJECT: Mathematics
TOPIC: Percentages
CLASS: JHS 2
DURATION: 80 minutes
CLASS SIZE: 37

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- construct the main idea of profit
- evaluate fraction

PCK:
Content is accurate throughout, anticipates common misconceptions for profit, and includes pitched worked examples.

RESOURCES:
a labelled diagram of profit; a whiteboard marker for key terms; counters for the group task.

INTRODUCTION:
Teacher begins the lesson.

CORE POINTS:
Percentages involves profit. Learners should note that profit is a key point of today's lesson.
Percentages involves fraction. Learners should note that fraction is a key point of today's lesson.
Percentages involves decimal. Learners should note that decimal is a key point of today's lesson.
Percentages involves discount. Learners should note that discount is a key point of today's lesson.
Percentages involves conversion. Learners should note that conversion is a key point of today's lesson.
Percentages involves percent. Learners should note that percent is a key point of today's lesson.
Percentages involves profit. Learners should note that profit is a key point of today's lesson.
Percentages involves fraction. Learners should note that fraction is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(20 minutes) Learners role-play the process of profit in front of the class.
(10 minutes) Teacher writes notes about fraction on the board for learners to copy.
(10 minutes) Teacher demonstrates decimal using TLMs while learners observe and ask questions.
(10 minutes) Through question and answer, learners brainstorm what they know about discount.
(20 minutes) In groups, learners investigate conversion and record their observations.

EVALUATION:
1. Copy the notes from the board neatly into your exercise book.
2. Explain the role of fraction in your own words.

DIFFERENTIATION:
Groups are mixed ability so learners support one another. Slower learners receive targeted support during the group work. Participation is shared fairly between girls and boys.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain profit clearly.

SEQUENCING:
Starter, main, and plenary all present with coherent progression; each activity builds on the previous; timings are realistic and balanced. Phase timings are shown throughout.

CLOSURE:
Teacher summarises the key points of the lesson. Learners state the key points to the class. Closing questions check whether the objective was met.
