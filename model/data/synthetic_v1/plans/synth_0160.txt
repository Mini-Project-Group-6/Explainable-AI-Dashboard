SUBJECT: Integrated Science
TOPIC: Photosynthesis
CLASS: JHS 1
DURATION: 70 minutes
CLASS SIZE: 40

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- calculate a curriculum indicator for Photosynthesis using with the aid of real objects evidence
- evaluate the key idea of glucose in one lesson
- construct leaf with a clear example

PCK:
Content is broadly correct but thin and generic for glucose.

RESOURCES:
worksheets on glucose; counters for the group task; a phone image of chlorophyll.

INTRODUCTION:
This is connected to today's topic, Photosynthesis, and in particular to glucose.

CORE POINTS:
Photosynthesis involves glucose. Learners should note that glucose is a key point of today's lesson.
Photosynthesis involves leaf. Learners should note that leaf is a key point of today's lesson.
Photosynthesis involves chlorophyll. Learners should note that chlorophyll is a key point of today's lesson.
Photosynthesis involves plants. Learners should note that plants is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(10 minutes) Learners practise solving exercises on glucose in pairs.
(10 minutes) Teacher demonstrates leaf using TLMs while learners observe and ask questions.
(10 minutes) Teacher explains chlorophyll to the class.
(10 minutes) In groups, learners investigate plants and record their observations.
(15 minutes) Learners practise solving exercises on carbon dioxide in pairs.

EVALUATION:
1. List 2 examples of glucose.

DIFFERENTIATION:
Key terms are explained in the local language where needed. A support task with scaffolded steps is prepared for learners who struggle. An extension task is ready for learners who finish early.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain glucose clearly.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
The main points are consolidated on the board. Learners state the key points to the class. Closing questions check whether the objective was met.
