SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 2
DURATION: 60 minutes
CLASS SIZE: 46

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- identify a curriculum indicator for Comprehension Skills using using the chart provided evidence
- state the key idea of inference in one lesson
- compare passage with a clear example

PCK:
Content is accurate throughout, anticipates common misconceptions for inference, and includes pitched worked examples.

RESOURCES:
a projector where power is available; a ruler and measuring tape; a whiteboard marker for key terms; flashcards for main idea.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Teacher reviews learners' previous knowledge of summary. This is connected to today's topic, Comprehension Skills, and in particular to inference. The objective is shared with learners at the start.

CORE POINTS:
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(15 minutes) Through question and answer, learners brainstorm what they know about inference.
(20 minutes) Learners practise solving exercises on passage in pairs.
(20 minutes) Teacher demonstrates context clues using TLMs while learners observe and ask questions.
(10 minutes) Teacher reads the section on main idea from the textbook.
(10 minutes) Learners role-play the process of summary in front of the class.

EVALUATION:
1. What is meant by inference?
2. Calculate the answer to the exercise on passage on the board.
3. Calculate the answer to the exercise on context clues on the board.
4. What is meant by main idea?

DIFFERENTIATION:
Questions are directed equally across the class. A challenge question is provided for the most able. Provision is made for a learner with a hearing impairment. Groups are mixed ability so learners support one another.

EXPLANATION STRATEGY:
Teacher uses an analogy, diagram, and demonstration from the Ghanaian classroom context to explain inference.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
Teacher summarises the key points of the lesson. Teacher asks two questions to confirm attainment before dismissal.
