SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 3
DURATION: 80 minutes
CLASS SIZE: 27

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- classify a curriculum indicator for Comprehension Skills using with the aid of real objects evidence
- demonstrate the key idea of passage in one lesson
- identify inference with a clear example

PCK:
Content is accurate and appropriate to grade level with worked examples for passage.

RESOURCES:
a projector where power is available; a whiteboard marker for key terms; a ruler and measuring tape.

INTRODUCTION:
Learners recall what they already know about main idea. This is connected to today's topic, Comprehension Skills, and in particular to passage. The objective is shared with learners at the start.

CORE POINTS:
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves summary. Learners should note that summary is a key point of today's lesson.
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(15 minutes) Teacher writes notes about passage on the board for learners to copy.
(10 minutes) Teacher demonstrates inference using TLMs while learners observe and ask questions.
(20 minutes) Learners draw and label a chart of summary in their exercise books.
(20 minutes) Learners draw and label a chart of context clues in their exercise books.
(15 minutes) Learners draw and label a chart of main idea in their exercise books.
(10 minutes) Learners role-play the process of passage in front of the class.

EVALUATION:
1. What is meant by passage?
2. Calculate the answer to the exercise on inference on the board.

DIFFERENTIATION:
Slower learners receive targeted support during the group work. Learners are grouped by ability for the practice task. Participation is shared fairly between girls and boys. An extension task is ready for learners who finish early.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain passage clearly.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
The main points are consolidated on the board. Teacher asks two questions to confirm attainment before dismissal.
