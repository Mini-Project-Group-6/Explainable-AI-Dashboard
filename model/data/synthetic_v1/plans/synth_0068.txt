SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 1
DURATION: 80 minutes
CLASS SIZE: 44

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- appreciate context clues

PCK:
Content is broadly correct but thin and generic for context clues.

RESOURCES:
cardboard cut-outs prepared beforehand; a projector where power is available; chalkboard and chalk.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Teacher reviews learners' previous knowledge of main idea. This is connected to today's topic, Comprehension Skills, and in particular to context clues. The objective is shared with learners at the start.

CORE POINTS:
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves summary. Learners should note that summary is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(20 minutes) Learners practise solving exercises on context clues in pairs.
(15 minutes) Learners practise solving exercises on passage in pairs.
(20 minutes) Teacher reads the section on inference from the textbook.

EVALUATION:
1. What is meant by context clues?
2. Describe how passage occurs.

DIFFERENTIATION:
A support task with scaffolded steps is prepared for learners who struggle.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain context clues clearly.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
The main points are consolidated on the board. Closing questions check whether the objective was met.
