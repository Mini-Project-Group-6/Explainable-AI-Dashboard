SUBJECT: Integrated Science
TOPIC: Simple Machines
CLASS: JHS 3
DURATION: 80 minutes
CLASS SIZE: 54

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- explain a curriculum indicator for Simple Machines using correctly evidence
- evaluate the key idea of inclined plane in one lesson
- list fulcrum with a clear example

PCK:
Content is accurate throughout, anticipates common misconceptions for inclined plane, and includes pitched worked examples.

RESOURCES:
worksheets on inclined plane; chalkboard and chalk.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Teacher reviews learners' previous knowledge of effort. This is connected to today's topic, Simple Machines, and in particular to inclined plane.

CORE POINTS:
Simple Machines involves inclined plane. Learners should note that inclined plane is a key point of today's lesson.
Simple Machines involves fulcrum. Learners should note that fulcrum is a key point of today's lesson.
Simple Machines involves pulley. Learners should note that pulley is a key point of today's lesson.
Simple Machines involves lever. Learners should note that lever is a key point of today's lesson.
Simple Machines involves load. Learners should note that load is a key point of today's lesson.
Simple Machines involves effort. Learners should note that effort is a key point of today's lesson.
Simple Machines involves inclined plane. Learners should note that inclined plane is a key point of today's lesson.
Simple Machines involves fulcrum. Learners should note that fulcrum is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(10 minutes) Learners role-play the process of inclined plane in front of the class.
(15 minutes) Learners practise solving exercises on fulcrum in pairs.
(10 minutes) Teacher writes notes about pulley on the board for learners to copy.
(10 minutes) Learners draw and label a chart of lever in their exercise books.

EVALUATION:
1. What is meant by inclined plane?
2. Calculate the answer to the exercise on fulcrum on the board.
3. Describe how pulley occurs.
4. What is meant by lever?

DIFFERENTIATION:
Learners are grouped by ability for the practice task. Provision is made for a learner with a hearing impairment. Slower learners receive targeted support during the group work.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain inclined plane clearly.

SEQUENCING:
Starter, main, and plenary all present with coherent progression; each activity builds on the previous; timings are realistic and balanced. Phase timings are shown throughout.

CLOSURE:
Teacher summarises the key points of the lesson. Learners state the key points to the class. Teacher asks two questions to confirm attainment before dismissal.
