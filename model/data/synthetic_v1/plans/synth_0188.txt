SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 1
DURATION: 80 minutes
CLASS SIZE: 25

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- be aware of inference

PCK:
Content is accurate and appropriate to grade level with worked examples for inference.

RESOURCES:
cardboard cut-outs prepared beforehand; specimens of passage; a wall chart showing summary.

INTRODUCTION:
Teacher opens with a short hook to settle the class. This is connected to today's topic, Comprehension Skills, and in particular to inference. The objective is shared with learners at the start.

CORE POINTS:
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves summary. Learners should note that summary is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(10 minutes) Learners practise solving exercises on inference in pairs.
(20 minutes) Through question and answer, learners brainstorm what they know about passage.
(15 minutes) Learners discuss summary in small groups and present their findings to the class.
(10 minutes) Through question and answer, learners brainstorm what they know about main idea.
(10 minutes) Teacher reads the section on context clues from the textbook.

EVALUATION:
1. Describe how inference occurs.
2. What is meant by passage?

DIFFERENTIATION:
A challenge question is provided for the most able. Key terms are explained in the local language where needed. Participation is shared fairly between girls and boys.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain inference clearly.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
The main points are consolidated on the board. Learners state the key points to the class. Teacher asks two questions to confirm attainment before dismissal.
