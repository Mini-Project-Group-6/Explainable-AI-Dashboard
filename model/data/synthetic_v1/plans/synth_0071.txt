SUBJECT: Integrated Science
TOPIC: Photosynthesis
CLASS: JHS 3
DURATION: 42 minutes
CLASS SIZE: 31

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- know plants

PCK:
Content is accurate and appropriate to grade level with worked examples for plants.

RESOURCES:
flashcards for plants; cardboard cut-outs prepared beforehand.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Teacher revises the previous lesson on sunlight.

CORE POINTS:
Photosynthesis involves plants. Learners should note that plants is a key point of today's lesson.
Photosynthesis involves leaf. Learners should note that leaf is a key point of today's lesson.
Photosynthesis involves chlorophyll. Learners should note that chlorophyll is a key point of today's lesson.
Photosynthesis involves oxygen. Learners should note that oxygen is a key point of today's lesson.
Photosynthesis involves carbon dioxide. Learners should note that carbon dioxide is a key point of today's lesson.
Photosynthesis involves glucose. Learners should note that glucose is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
Teacher writes notes about plants on the board for learners to copy.
Learners discuss leaf in small groups and present their findings to the class.
Teacher demonstrates chlorophyll using TLMs while learners observe and ask questions.
Learners practise solving exercises on oxygen in pairs.

EVALUATION:
1. What is meant by plants?
2. What is meant by leaf?
3. Calculate the answer to the exercise on chlorophyll on the board.

DIFFERENTIATION:
Learners may first discuss in their mother tongue.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain plants clearly.

SEQUENCING:
A phase is missing and timings are absent.

CLOSURE:
The main points are consolidated on the board.
