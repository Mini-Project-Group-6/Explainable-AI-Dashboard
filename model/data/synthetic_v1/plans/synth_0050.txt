SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 2
DURATION: 60 minutes
CLASS SIZE: 44

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- evaluate the main idea of inference
- explain context clues

PCK:
Content is accurate and appropriate to grade level with worked examples for inference.

RESOURCES:
a whiteboard marker for key terms.

INTRODUCTION:
This is connected to today's topic, Comprehension Skills, and in particular to inference.

CORE POINTS:
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.
Comprehension Skills involves summary. Learners should note that summary is a key point of today's lesson.
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(10 minutes) Learners role-play the process of inference in front of the class.
(15 minutes) Teacher explains context clues to the class.
(10 minutes) Teacher explains passage to the class.

EVALUATION:
1. Calculate the answer to the exercise on inference on the board.
2. Describe how context clues occurs.
3. List 4 examples of passage.

DIFFERENTIATION:
Participation is shared fairly between girls and boys. Slower learners receive targeted support during the group work.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain inference clearly.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
The main points are consolidated on the board. Learners summarise in their own words what they have learnt. Teacher asks two questions to confirm attainment before dismissal.
