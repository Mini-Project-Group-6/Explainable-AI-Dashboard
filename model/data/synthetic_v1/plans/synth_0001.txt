SUBJECT: Mathematics
TOPIC: Fractions
CLASS: JHS 1
DURATION: 70 minutes
CLASS SIZE: 48

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- calculate a curriculum indicator for Fractions using at least two evidence
- construct the key idea of equivalent fractions in one lesson
- classify denominator with a clear example

PCK:
Content is accurate throughout, anticipates common misconceptions for equivalent fractions, and includes pitched worked examples.

RESOURCES:
a phone image of equivalent fractions; chalkboard and chalk; flashcards for simplify; counters for the group task.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Teacher revises the previous lesson on numerator. This is connected to today's topic, Fractions, and in particular to equivalent fractions. The objective is shared with learners at the start.

CORE POINTS:
Fractions involves equivalent fractions. Learners should note that equivalent fractions is a key point of today's lesson.
Fractions involves denominator. Learners should note that denominator is a key point of today's lesson.
Fractions involves simplify. Learners should note that simplify is a key point of today's lesson.
Fractions involves addition. Learners should note that addition is a key point of today's lesson.
Fractions involves numerator. Learners should note that numerator is a key point of today's lesson.
Fractions involves equivalent fractions. Learners should note that equivalent fractions is a key point of today's lesson.
Fractions involves denominator. Learners should note that denominator is a key point of today's lesson.
Fractions involves simplify. Learners should note that simplify is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(10 minutes) Learners practise solving exercises on equivalent fractions in pairs.
(15 minutes) Teacher writes notes about denominator on the board for learners to copy.
(10 minutes) Teacher demonstrates simplify using TLMs while learners observe and ask questions.
(10 minutes) In groups, learners investigate addition and record their observations.
(15 minutes) Learners practise solving exercises on numerator in pairs.
(15 minutes) Teacher demonstrates equivalent fractions using TLMs while learners observe and ask questions.

EVALUATION:
1. Describe how equivalent fractions occurs.
2. Describe how denominator occurs.
3. Describe how simplify occurs.
4. Explain the role of addition in your own words.

DIFFERENTIATION:
Learners are grouped by ability for the practice task. Provision is made for a learner with a hearing impairment. Participation is shared fairly between girls and boys.

EXPLANATION STRATEGY:
Teacher uses an analogy, diagram, and demonstration from the Ghanaian classroom context to explain equivalent fractions.

SEQUENCING:
Starter, main, and plenary all present with coherent progression; each activity builds on the previous; timings are realistic and balanced. Phase timings are shown throughout.

CLOSURE:
The main points are consolidated on the board. Learners summarise in their own words what they have learnt. Closing questions check whether the objective was met.
