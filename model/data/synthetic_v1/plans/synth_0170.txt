SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 1
DURATION: 80 minutes
CLASS SIZE: 43

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- identify a curriculum indicator for Comprehension Skills using correctly evidence
- compare the key idea of inference in one lesson
- identify context clues with a clear example

PCK:
Content is accurate throughout, anticipates common misconceptions for inference, and includes pitched worked examples.

RESOURCES:
specimens of inference; flashcards for context clues.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Teacher reviews learners' previous knowledge of summary. This is connected to today's topic, Comprehension Skills, and in particular to inference. The objective is shared with learners at the start.

CORE POINTS:
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves summary. Learners should note that summary is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(15 minutes) Learners role-play the process of inference in front of the class.
(15 minutes) Teacher writes notes about context clues on the board for learners to copy.
(15 minutes) Through question and answer, learners brainstorm what they know about main idea.
(20 minutes) In groups, learners investigate passage and record their observations.

EVALUATION:
1. Calculate the answer to the exercise on inference on the board.
2. Calculate the answer to the exercise on context clues on the board.
3. List 2 examples of main idea.
4. List 2 examples of passage.

DIFFERENTIATION:
Learners may first discuss in their mother tongue. A challenge question is provided for the most able.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain inference clearly.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
The main points are consolidated on the board. Learners summarise in their own words what they have learnt. Closing questions check whether the objective was met.
