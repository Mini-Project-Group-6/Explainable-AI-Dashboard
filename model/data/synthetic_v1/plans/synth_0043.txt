SUBJECT: Integrated Science
TOPIC: The Water Cycle
CLASS: JHS 2
DURATION: 60 minutes
CLASS SIZE: 25

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- state a curriculum indicator for The Water Cycle using using the chart provided evidence
- classify the key idea of evaporation in one lesson
- describe rivers with a clear example

PCK:
Content is accurate and appropriate to grade level with worked examples for evaporation.

RESOURCES:
a ruler and measuring tape; a whiteboard marker for key terms.

INTRODUCTION:
The objective is shared with learners at the start.

CORE POINTS:
The Water Cycle involves evaporation. Learners should note that evaporation is a key point of today's lesson.
The Water Cycle involves rivers. Learners should note that rivers is a key point of today's lesson.
The Water Cycle involves condensation. Learners should note that condensation is a key point of today's lesson.
The Water Cycle involves rainfall. Learners should note that rainfall is a key point of today's lesson.
The Water Cycle involves clouds. Learners should note that clouds is a key point of today's lesson.
The Water Cycle involves precipitation. Learners should note that precipitation is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(10 minutes) In groups, learners investigate evaporation and record their observations.
(10 minutes) In groups, learners investigate rivers and record their observations.
(20 minutes) Teacher explains condensation to the class.

EVALUATION:
1. Describe how evaporation occurs.
2. Describe how rivers occurs.
3. What is meant by condensation?
4. Explain the role of rainfall in your own words.

DIFFERENTIATION:
Groups are mixed ability so learners support one another. Learners with special educational needs are seated in front and given adapted materials.

EXPLANATION STRATEGY:
Teacher uses an analogy, diagram, and demonstration from the Ghanaian classroom context to explain evaporation.

SEQUENCING:
Starter, main, and plenary all present with coherent progression; each activity builds on the previous; timings are realistic and balanced. Phase timings are shown throughout.

CLOSURE:
The main points are consolidated on the board.
