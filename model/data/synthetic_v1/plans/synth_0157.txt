SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 2
DURATION: 80 minutes
CLASS SIZE: 25

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- classify the main idea of main idea
- explain context clues

PCK:
Content is accurate and appropriate to grade level with worked examples for main idea.

RESOURCES:
a ruler and measuring tape; chalkboard and chalk; flashcards for inference; a projector where power is available.

INTRODUCTION:
Teacher revises the previous lesson on passage. This is connected to today's topic, Comprehension Skills, and in particular to main idea. The objective is shared with learners at the start.

CORE POINTS:
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves summary. Learners should note that summary is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(15 minutes) Teacher writes notes about main idea on the board for learners to copy.
(10 minutes) Learners draw and label a chart of context clues in their exercise books.
(15 minutes) Teacher reads the section on inference from the textbook.
(10 minutes) Learners draw and label a chart of summary in their exercise books.
(20 minutes) Learners discuss passage in small groups and present their findings to the class.

EVALUATION:
1. Describe how main idea occurs.
2. Explain the role of context clues in your own words.
3. Explain the role of inference in your own words.

DIFFERENTIATION:
An extension task is ready for learners who finish early. A support task with scaffolded steps is prepared for learners who struggle. Participation is shared fairly between girls and boys.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain main idea clearly.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
Teacher summarises the key points of the lesson. Learners summarise in their own words what they have learnt. Closing questions check whether the objective was met.
