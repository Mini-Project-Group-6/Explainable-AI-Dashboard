SUBJECT: English Language
TOPIC: Nouns and Pronouns
CLASS: JHS 2
DURATION: 60 minutes
CLASS SIZE: 41

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- solve the main idea of common noun
- explain pronoun

PCK:
Content is accurate throughout, anticipates common misconceptions for common noun, and includes pitched worked examples.

RESOURCES:
cardboard cut-outs prepared beforehand; a whiteboard marker for key terms; specimens of noun.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Learners recall what they already know about subject. The objective is shared with learners at the start.

CORE POINTS:
Nouns and Pronouns involves common noun. Learners should note that common noun is a key point of today's lesson.
Nouns and Pronouns involves pronoun. Learners should note that pronoun is a key point of today's lesson.
Nouns and Pronouns involves noun. Learners should note that noun is a key point of today's lesson.
Nouns and Pronouns involves sentence. Learners should note that sentence is a key point of today's lesson.
Nouns and Pronouns involves proper noun. Learners should note that proper noun is a key point of today's lesson.
Nouns and Pronouns involves subject. Learners should note that subject is a key point of today's lesson.
Nouns and Pronouns involves common noun. Learners should note that common noun is a key point of today's lesson.
Nouns and Pronouns involves pronoun. Learners should note that pronoun is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(15 minutes) Through question and answer, learners brainstorm what they know about common noun.
(15 minutes) Learners role-play the process of pronoun in front of the class.
(15 minutes) Learners role-play the process of noun in front of the class.
(10 minutes) Teacher reads the section on sentence from the textbook.

EVALUATION:
1. What is meant by common noun?
2. What is meant by pronoun?
3. What is meant by noun?
4. List 3 examples of sentence.

DIFFERENTIATION:
Questions are directed equally across the class. A challenge question is provided for the most able. Groups are mixed ability so learners support one another. Key terms are explained in the local language where needed.

EXPLANATION STRATEGY:
Teacher uses an analogy, diagram, and demonstration from the Ghanaian classroom context to explain common noun.

SEQUENCING:
Starter, main, and plenary all present with coherent progression; each activity builds on the previous; timings are realistic and balanced. Phase timings are shown throughout.

CLOSURE:
Teacher summarises the key points of the lesson. Learners state the key points to the class. Closing questions check whether the objective was met.
