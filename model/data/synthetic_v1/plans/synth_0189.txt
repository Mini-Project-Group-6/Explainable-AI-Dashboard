SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 2
DURATION: 70 minutes
CLASS SIZE: 28

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- evaluate a curriculum indicator for Comprehension Skills using at least three evidence
- describe the key idea of main idea in one lesson
- compare inference with a clear example

PCK:
Content is accurate throughout, anticipates common misconceptions for main idea, and includes pitched worked examples.

RESOURCES:
a short video clip on main idea; flashcards for inference; a simple model of passage; a whiteboard marker for key terms.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Learners recall what they already know about context clues. This is connected to today's topic, Comprehension Skills, and in particular to main idea. The objective is shared with learners at the start.

CORE POINTS:
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves summary. Learners should note that summary is a key point of today's lesson.
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.

Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(10 minutes) Teacher demonstrates main idea using TLMs while learners observe and ask questions.
(20 minutes) Learners discuss inference in small groups and present their findings to the class.
(15 minutes) Learners practise solving exercises on passage in pairs.
(10 minutes) Learners draw and label a chart of summary in their exercise books.
(20 minutes) Teacher reads the section on context clues from the textbook.
(15 minutes) Learners discuss main idea in small groups and present their findings to the class.

EVALUATION:
1. Calculate the answer to the exercise on main idea on the board.
2. List 3 examples of inference.
3. What is meant by passage?
4. List 2 examples of summary.

DIFFERENTIATION:
Learners with special educational needs are seated in front and given adapted materials. Learners are grouped by ability for the practice task. A challenge question is provided for the most able.

EXPLANATION STRATEGY:
Teacher uses an analogy, diagram, and demonstration from the Ghanaian classroom context to explain main idea.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
Teacher summarises the key points of the lesson. Learners summarise in their own words what they have learnt. Closing questions check whether the objective was met.
