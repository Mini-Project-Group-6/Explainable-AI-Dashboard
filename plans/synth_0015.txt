SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 1
DURATION: 36 minutes
CLASS SIZE: 52

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- know inference

PCK:
Content is broadly correct but thin and generic for inference.

RESOURCES:
a simple model of inference.

INTRODUCTION:
Teacher opens with a short hook to settle the class. This is connected to today's topic, Comprehension Skills, and in particular to inference. The objective is shared with learners at the start.

CORE POINTS:
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
Learners role-play the process of inference in front of the class.
Learners role-play the process of main idea in front of the class.
Learners discuss context clues in small groups and present their findings to the class.
Teacher reads the section on passage from the textbook.

EVALUATION:
1. Describe how inference occurs.
2. What is meant by main idea?
3. Calculate the answer to the exercise on context clues on the board.

DIFFERENTIATION:
A challenge question is provided for the most able. Provision is made for a learner with a hearing impairment.

EXPLANATION STRATEGY:
Teacher uses familiar examples to explain inference clearly.

SEQUENCING:
A phase is missing and timings are absent.

CLOSURE:
Learners summarise in their own words what they have learnt. Closing questions check whether the objective was met.
