SUBJECT: Mathematics
TOPIC: Percentages
CLASS: JHS 3
DURATION: 60 minutes
CLASS SIZE: 31

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- compare a curriculum indicator for Percentages using at least three evidence
- explain the key idea of decimal in one lesson
- classify percent with a clear example

PCK:
Content is accurate throughout, anticipates common misconceptions for decimal, and includes pitched worked examples.

RESOURCES:
a labelled diagram of decimal; chalkboard and chalk; a phone image of fraction.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Teacher revises the previous lesson on discount. This is connected to today's topic, Percentages, and in particular to decimal. The objective is shared with learners at the start.

CORE POINTS:
Percentages involves decimal. Learners should note that decimal is a key point of today's lesson.
Percentages involves percent. Learners should note that percent is a key point of today's lesson.
Percentages involves fraction. Learners should note that fraction is a key point of today's lesson.
Percentages involves conversion. Learners should note that conversion is a key point of today's lesson.
Percentages involves profit. Learners should note that profit is a key point of today's lesson.
Percentages involves discount. Learners should note that discount is a key point of today's lesson.
Percentages involves decimal. Learners should note that decimal is a key point of today's lesson.
Percentages involves percent. Learners should note that percent is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(15 minutes) Teacher demonstrates decimal using TLMs while learners observe and ask questions.
(15 minutes) Learners discuss percent in small groups and present their findings to the class.
(10 minutes) Teacher demonstrates fraction using TLMs while learners observe and ask questions.
(15 minutes) Teacher reads the section on conversion from the textbook.
(10 minutes) Teacher demonstrates profit using TLMs while learners observe and ask questions.

EVALUATION:
1. Calculate the answer to the exercise on decimal on the board.
2. Explain the role of percent in your own words.
3. Calculate the answer to the exercise on fraction on the board.

DIFFERENTIATION:
Slower learners receive targeted support during the group work.

EXPLANATION STRATEGY:
Teacher uses an analogy, diagram, and demonstration from the Ghanaian classroom context to explain decimal.

SEQUENCING:
Starter, main, and plenary all present with coherent progression; each activity builds on the previous; timings are realistic and balanced. Phase timings are shown throughout.

CLOSURE:
Learners summarise in their own words what they have learnt.
