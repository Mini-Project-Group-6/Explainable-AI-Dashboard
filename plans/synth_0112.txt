SUBJECT: Integrated Science
TOPIC: Photosynthesis
CLASS: JHS 3
DURATION: 60 minutes
CLASS SIZE: 42

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- describe the main idea of sunlight
- compare oxygen

PCK:
Content is accurate throughout, anticipates common misconceptions for sunlight, and includes pitched worked examples.

RESOURCES:
a whiteboard marker for key terms.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Teacher revises the previous lesson on carbon dioxide. This is connected to today's topic, Photosynthesis, and in particular to sunlight. The objective is shared with learners at the start.

CORE POINTS:
Photosynthesis involves sunlight. Learners should note that sunlight is a key point of today's lesson.
Photosynthesis involves oxygen. Learners should note that oxygen is a key point of today's lesson.
Photosynthesis involves glucose. Learners should note that glucose is a key point of today's lesson.
Photosynthesis involves leaf. Learners should note that leaf is a key point of today's lesson.
Photosynthesis involves chlorophyll. Learners should note that chlorophyll is a key point of today's lesson.
Photosynthesis involves plants. Learners should note that plants is a key point of today's lesson.
Photosynthesis involves carbon dioxide. Learners should note that carbon dioxide is a key point of today's lesson.
Photosynthesis involves sunlight. Learners should note that sunlight is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(20 minutes) Learners practise solving exercises on sunlight in pairs.
(15 minutes) Teacher reads the section on oxygen from the textbook.
(10 minutes) Through question and answer, learners brainstorm what they know about glucose.
(10 minutes) Learners practise solving exercises on leaf in pairs.

EVALUATION:
1. List 4 examples of sunlight.
2. List 2 examples of oxygen.
3. What is meant by glucose?
4. Describe how leaf occurs.

DIFFERENTIATION:
Key terms are explained in the local language where needed. Questions are directed equally across the class. Slower learners receive targeted support during the group work. An extension task is ready for learners who finish early.

EXPLANATION STRATEGY:
Teacher uses an analogy, diagram, and demonstration from the Ghanaian classroom context to explain sunlight.

SEQUENCING:
Starter, main, and plenary are present and ordered. Timings are allocated.

CLOSURE:
Learners state the key points to the class. Closing questions check whether the objective was met.
