SUBJECT: English Language
TOPIC: Comprehension Skills
CLASS: JHS 2
DURATION: 80 minutes
CLASS SIZE: 28

OBJECTIVES:
By the end of the lesson, the learner will be able to:
- identify the main idea of context clues
- list passage

PCK:
Content is accurate throughout, anticipates common misconceptions for context clues, and includes pitched worked examples.

RESOURCES:
a whiteboard marker for key terms.

INTRODUCTION:
Teacher opens with a short hook to settle the class. Learners recall what they already know about summary. This is connected to today's topic, Comprehension Skills, and in particular to context clues. The objective is shared with learners at the start.

CORE POINTS:
Comprehension Skills involves context clues. Learners should note that context clues is a key point of today's lesson.
Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.
Comprehension Skills involves inference. Learners should note that inference is a key point of today's lesson.
Comprehension Skills involves summary. Learners should note that summary is a key point of today's lesson.

Comprehension Skills involves passage. Learners should note that passage is a key point of today's lesson.
Comprehension Skills involves main idea. Learners should note that main idea is a key point of today's lesson.

TEACHER-LEARNER ACTIVITIES:
(20 minutes) Learners practise solving exercises on context clues in pairs.
(15 minutes) Teacher writes notes about passage on the board for learners to copy.
(20 minutes) Learners practise solving exercises on main idea in pairs.
(20 minutes) Teacher demonstrates inference using TLMs while learners observe and ask questions.
(10 minutes) Through question and answer, learners brainstorm what they know about summary.

EVALUATION:
1. What is meant by context clues?
2. Calculate the answer to the exercise on passage on the board.
3. List 3 examples of main idea.
4. What is meant by inference?

DIFFERENTIATION:
Learners may first discuss in their mother tongue. Learners with special educational needs are seated in front and given adapted materials. A challenge question is provided for the most able.

EXPLANATION STRATEGY:
Teacher uses an analogy, diagram, and demonstration from the Ghanaian classroom context to explain context clues.

SEQUENCING:
Starter, main, and plenary all present with coherent progression; each activity builds on the previous; timings are realistic and balanced. Phase timings are shown throughout.

CLOSURE:
The main points are consolidated on the board. Learners state the key points to the class. Teacher asks two questions to confirm attainment before dismissal.
